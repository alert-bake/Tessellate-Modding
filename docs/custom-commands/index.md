# Custom Commands

Custom commands are an existing part of Tessellate's current modding surface.

This page is intentionally limited to that confirmed fact. It does not invent a registration API, callback signature, permission model, or command lifecycle.

## Documentation status

The implementation needs to be inspected before documenting the exact authoring contract.
